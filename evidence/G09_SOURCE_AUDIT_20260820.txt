3. BUFFER / VIEW POSTCONDITION AUTHORITY
===============================================================================

graphium/adapters/gtk/editor_buffer.py:94-123
  GtkTextBufferPort.apply_operations() applies exact ReplayOperation sequences and then projects an
  explicit ViewState. Expected DELETE text is verified before deletion; the port maintains rolling
  inverse operations for failure rollback. ViewState contains separate insert/bound offsets, so
  reversed selection direction is representable and must not be normalized away by G09.

graphium/domain/edit_history.py:165-304
  DeltaHistory records one explicit group, generates one fresh state ID only when deltas exist, and
  stores before/after ViewState for exact Undo/Redo projection. Empty groups do not advance state.

Conclusion
  Every adopted G09 action must produce an immutable GTK-free plan carrying source state, source
  text, final text, operations, before_view and target_view. Selection direction is a contract datum.
